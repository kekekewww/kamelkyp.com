# 法務審查 Checklist

本文件是發布前的需求核對表，不是法律意見。必須交由熟悉臺灣適用法律與跨境委託的專業人士確認；完成前 `LEGAL_REVIEW_CONFIRMED` 保持 `false`。

- [ ] 線上勾選、送出、電子紀錄與雙方確認能否成立有效契約。
- [ ] 未成年人只勾選「監護人已授權」的做法是否足夠，以及需要的補充程序。
- [ ] 學生身分證明、可遮蔽敏感資訊、人工接受／拒絕與全價格 -30% 的文字。
- [ ] 銀行匯款、PayPal、確認接案後 50% 訂金、預覽確認後尾款。
- [ ] 甲方取消時訂金不退；案件暫停、重新排隊與 7 日未回覆規則。
- [ ] 明確分開兩種乙方情況：
  - Kamel 因自身原因延遲但仍完成：總價調整為原應付總額 60%。
  - Kamel 確定無法完成：退還已收訂金。
- [ ] 前 5 次小修改免費；第 6 次起每次為鎖定初始報價 10%，基準不累加。
- [ ] 第 1 次重大修改免費；第 2 次起每次為鎖定初始報價 50%；重大修改需先告知。
- [ ] 正式交付後工程檔加購為鎖定初始報價 50%；工程至少保存 7 日但不保證永久保存。
- [ ] 甲方擁有人聲、原創歌曲、伴奏與分軌的權利；Kamel 擁有工程檔。
- [ ] 公開使用只需 credit；作品集授權另行選擇，可拒絕且不影響接案。
- [ ] 作品發布前或甲方另行同意前的保密義務。
- [ ] 用途說明不影響報價；急件、諮詢、素材整理以服務基價分別計算、不複利。
- [ ] 完整表單、Google Form、Sheet、Gmail、學生證明連結的保存、刪除與平台備份說明。
- [ ] 永久去識別案件紀錄六欄的必要性與合法基礎。
- [ ] 英文 USD 依送出時匯率鎖定、跨境付款、PayPal 費用與匯率風險文字。
- [ ] 中英文版本的法律效果、優先語言與爭議處理／管轄條款。

審查完成後，由 Kamel 在 GitHub `production` Environment 將 `LEGAL_REVIEW_CONFIRMED` 設為 `true`，再人工核准 production deployment。
